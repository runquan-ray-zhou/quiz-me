# QuizMe

## Synopsis

**Trivia Master** is a web application that provides users with an engaging and interactive platform to test their knowledge across various topics and difficulty levels. Using the Open Trivia Database (OpenTDB) API, the app generates trivia questions in different formats, including multiple-choice and true/false, ensuring a fun and challenging experience for users of all ages.

## Technology Utilized

- **React**: Frontend framework for building the user interface
- **OpenTDB API**: To fetch trivia questions across a wide range of topics and difficulty levels
- **CSS Modules**: For styling and creating a visually appealing design

## Features

- 🎯 Wide variety of trivia topics and difficulty levels
- ✅ Multiple-choice and true/false question formats
- 💡 Clean, user-friendly interface for an enjoyable experience

## Technical Details

The application leverages several key technologies to deliver a smooth and engaging user experience:

1. **Dynamic Trivia Questions**:
   - Fetches trivia questions from the OpenTDB API based on user-selected categories and difficulty levels
   - Supports multiple formats: multiple-choice and true/false

2. **Real-Time Interaction**:
   - Provides immediate feedback on user's answers

3. **Responsive Design**:
   - Adapts to various screen sizes for a smooth experience on desktops, tablets, and smartphones

## Usage

1. Open the application in your web browser.
2. Choose your preferred topic and difficulty level.
3. Start answering trivia questions in multiple-choice or true/false formats.
